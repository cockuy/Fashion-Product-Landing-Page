
# Fashion Product Landing Page

A minimalist fashion product landing page built using HTML and CSS as part of my frontend development journey.

## About

This project features a clean navigation bar, bold product typography, a product description, interactive product links, and a fashion photography section.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Hover effects
- Remix Icon
- Gilroy typography

## Features

- Minimal navigation menu
- Large product heading
- Product information section
- Add to Cart, Product Details, and Shipping links
- Hover interactions with arrow icons
- Full-width fashion image

## What I Learned

- Aligning elements using Flexbox
- Controlling spacing with padding and gap
- Styling interactive links with hover effects
- Working with typography and line height
- Using background-size and background-position

## Future Improvements

- Make the layout responsive on mobile devices
- Add functional cart interactions
- Improve accessibility
- Deploy with GitHub Pages
